# Технологии проекта PHP Functions Universe

## Языки программирования
- PHP 7.4+ (основной язык разработки)
- Markdown (документация)

## Требования к окружению
- PHP >= 7.4
- Расширение ext-mbstring (обязательно)
- Расширения по необходимости: ext-zip, ext-xml, ext-intl, ext-json

## Структура проекта
- PSR-4 автозагрузка классов
- Пространства имен: Inilim\Tool\
- Организация по функциональным категориям в директории src/Method/

## Инструменты разработки
- Composer (управление зависимостями)
- PHPUnit (тестирование)
- PHPStan (статический анализ)
- Twig (шаблонизация, опционально)
- PHP Metrics (анализ кода)
- Symfony Process (выполнение процессов)
- Symfony Finder (поиск файлов)

## Архитектурные паттерны
- Ленивая загрузка функций
- Статические фабрики
- Прокси-паттерн (через __callStatic)

## Файловая структура
- src/ - основной исходный код
- src/Method/ - файлы с отдельными функциями
- src/MethodMin/ - минифицированные версии функций
- tests/ - тесты
- build/ - скрипты сборки
- bench/ - бенчмарки

## Зависимости
- Основная библиотека не имеет внешних зависимостей
- Для разработки: PHPUnit, PHPStan, Twig, PHP Metrics, Symfony Process, Symfony Finder и другие инструменты
- Рекомендуемые расширения для оптимальной работы

## Поддерживаемые версии PHP
- Минимальная версия: PHP 7.4
- Поддержка современных версий PHP
- Обратная совместимость с более старыми версиями где возможно

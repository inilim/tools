# Повторяющиеся задачи проекта PHP Functions Universe

## Добавление новой функции

**Описание:** Процесс добавления новой функции в библиотеку

**Файлы для модификации:**
- `src/Method/{Category}/{function_name}.php` - файл с новой функцией
- `src/MethodMin/{Category}/{function_name}.php` - минифицированная версия (генерируется автоматически)

**Шаги:**
1. Создать файл с новой функцией в соответствующей категории в `src/Method/`
2. Убедиться, что функция объявлена в правильном пространстве имен (`Inilim\Tool\Method\{Category}\`)
3. Добавить типизацию и документацию согласно стандартам проекта
4. Запустить процесс минификации для генерации файла в `src/MethodMin/`
5. Протестировать работу новой функции через соответствующий класс-обертку

**Важные замечания:**
- Функция должна следовать принципам функционального программирования
- Все функции должны быть чистыми (pure functions) при возможности
- Необходимо соблюдать единый стиль кода проекта

## Добавление новой категории функций

**Описание:** Процесс добавления новой категории (нового класса) функций

**Файлы для модификации:**
- `src/{ClassName}.php` - новый класс-наследник LazyMethodAbstract
- Обновить документацию если необходимо

**Шаги:**
1. Создать новый класс в `src/` наследующийся от `LazyMethodAbstract`
2. Определить константы `NAME` и `IDX` для новой категории
3. Создать директорию `src/Method/{ClassName}/` для файлов функций
4. Создать директорию `src/MethodMin/{ClassName}/` для минифицированных файлов
5. Протестировать создание и вызов функций в новой категории

## Обновление архитектурных документов

**Описание:** Обновление документации архитектуры при изменениях в структуре проекта

**Файлы для модификации:**
- `memory-bank/architecture.md` - архитектурные изменения
- `memory-bank/tech.md` - изменения в технологиях
- `memory-bank/brief.md` - краткое описание при значительных изменениях
- `memory-bank/product.md` - функциональные изменения

**Шаги:**
1. Проанализировать изменения в архитектуре
2. Обновить соответствующие файлы документации
3. Убедиться в согласованности информации во всех файлах
4. Проверить актуальность примеров и описаний
